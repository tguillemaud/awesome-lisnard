# Guide de contribution

Merci de contribuer à **Awesome Lisnard**. Cette liste communautaire aide à découvrir des projets, outils et ressources liés à David Lisnard, à Nouvelle Énergie et aux initiatives associées.

## Proposer une ressource

Avant d'ouvrir une issue ou une pull request :

1. Vérifiez que la ressource n'est pas déjà dans le [README](../README.md) et qu'elle entre dans le périmètre du dépôt.
2. Ouvrez la page du projet pour confirmer qu'elle est accessible et comprendre ce qu'elle propose.
3. Rédigez une description courte, neutre et vérifiable, avec le lien direct le plus utile.
4. Si vous pensez que la ressource est publiée officiellement par Nouvelle Énergie ou David Lisnard, joignez une source publique qui le confirme. Ne déduisez pas son caractère officiel du nom ou de l'adresse du site. Le repère graphique est réservé aux ressources officielles.
5. Pour les statistiques, précisez les dates, sources ou limites connues qui aident à interpréter les chiffres.

Les initiatives indépendantes, critiques ou expérimentales sont recevables. Elles n'ont pas besoin d'être open source ni gratuites, mais doivent être publiques et apporter une utilité identifiable.

## Modifier la liste

Une pull request doit idéalement porter sur un changement cohérent et limité. Placez chaque ressource dans la catégorie existante la plus pertinente, gardez les descriptions à une phrase si possible, et évitez de reformuler les entrées sans rapport avec votre proposition.

Les issues servent à proposer une ressource, signaler un lien cassé ou demander une correction. Pour une modification prête, vous pouvez soumettre directement une pull request. Les modèles GitHub vous guideront.

## Vérifications avant envoi

- Le lien mène à la bonne ressource et fonctionne.
- La catégorie et la description correspondent à ce que la page permet de vérifier.
- Toute affirmation d'affiliation officielle est appuyée par une source publique.
- Le README reste lisible et le diff ne contient que les changements utiles.

La présence d'un lien dans la liste ne vaut pas approbation de son contenu, de ses méthodes ou de ses conclusions. Les statuts peuvent évoluer ; merci de signaler les informations à corriger.
